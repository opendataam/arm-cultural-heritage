# Тематические коллекции

Тематическая коллекция — размеченное подмножество Госкаталога внутри армянской тематики, например материалы об амшенских армянах. Коллекции строятся скриптом [`scripts/extract_collection.py`](../scripts/extract_collection.py) и не меняют основной реестр `data/terms.csv` и опубликованное извлечение `output/goskatalog/`.

## Определение коллекции

Каждая коллекция — каталог `data/collections/<id>/`:

| Файл | Назначение |
| --- | --- |
| `collection.json` | Идентификатор, название, описание, ссылки на файлы и правило кандидатов |
| `terms.csv` | Термины коллекции в формате [`data/terms.csv`](terms.md) |
| `labels.csv` | Ручная разметка `id,label,note` |

Пример `collection.json`:

```json
{
  "id": "hamshen",
  "title": "Амшенские армяне",
  "description": "…",
  "terms": "terms.csv",
  "labels": "labels.csv",
  "candidates": {
    "museum_pattern": "сочи|адлер|хостин|лазаревск|туапс",
    "exclude_museum_pattern": "островск",
    "note": "…"
  }
}
```

- `id` — латиница в нижнем регистре, цифры, `_` и `-`; используется в именах выходных файлов.
- `terms` обязателен, `labels` и `candidates` необязательны.
- `museum_pattern` и `exclude_museum_pattern` — regex по нормализованному `museum.name`; нормализация та же, что у терминов.

Термины проверяются тем же валидатором, что и основной реестр:

```bash
python3 scripts/terms.py data/collections/hamshen/terms.csv
```

## Уровни

| `collection_tier` | Как попадает запись |
| --- | --- |
| `confirmed` | Strong-термин коллекции в content-полях или метка `relevant` |
| `candidate` | Context-only термин, армянская запись (`include` основного извлечения) из музея по `museum_pattern` или метка `review` |

Метка `nonrelevant` удаляет запись из коллекции. Метка `relevant` или `review` добавляет запись по `id`, даже если правила её не нашли. Если `id` из меток нет в источнике, скрипт завершается с ошибкой.

## Выходные файлы

По умолчанию результат пишется в `output/goskatalog/collections/<id>/`:

- `<id>_records.parquet` — все поля источника и метаданные коллекции;
- `<id>_records.csv` — краткий список для ручной проверки: уровень, `id`, `gikNumber`, название, музей, период, термины, причины, решение основного извлечения, заметка метки;
- `report.json` — хэши определения, терминов и меток, счётчики, причины и пути.

Поля метаданных:

| Поле | Содержимое |
| --- | --- |
| `collection_id` | Идентификатор коллекции |
| `collection_tier` | `confirmed` или `candidate` |
| `collection_matched_entities`, `collection_matched_terms`, `collection_matched_fields` | Совпадения терминов коллекции |
| `collection_reasons` | `strong_content`, `context_only_unconfirmed`, `regional_museum`, `manual_relevant`, `manual_review` |
| `collection_label_note` | Заметка из `labels.csv` или `null` |
| `armenia_decision` | Решение основного извлечения: `include`, `review` или `null`, если записи там нет |

`armenia_decision = null` показывает пробелы основного реестра: такие записи найдены только терминами коллекции.

## Запуск

```bash
python3 scripts/extract_collection.py \
  --collection data/collections/hamshen \
  --input /path/to/goskatalog/data.parquet \
  --armenia-dir output/goskatalog \
  --threads 4 \
  --memory-limit 4GB
```

`--armenia-dir` должен содержать полные `armenia_records.parquet` и `armenia_review.parquet`. Полный проход по 31,7 млн записей занимает около 1,5 минуты.

## Коллекция `hamshen`

Амшенские армяне (амшенцы, хамшенцы, хемшины и хемшилы, хопские армяне) и диалект хомшецма. Термины на русском, армянском, английском и турецком учитывают словоформы и отсекают ложные подстроки вроде «Самшенко», «Памшена» и «Дамшен».

Кандидаты — армянские записи из музеев Сочи, Адлера, Хосты, Лазаревского и Туапсе: основная амшенская община России живёт на этом побережье. Литературно-мемориальный музей Н.А. Островского исключён: его армянские записи — переводы романов и письма писателю. Первичная ручная разметка в `labels.csv` отсеивает явный шум: репродукции Айвазовского, монеты, значки, марки, грампластинки, теплоход «Армения». Оставшиеся кандидаты требуют проверки: среди них предметы быта армянских переселенцев, негативы экспедиции по армянским сёлам Туапсинского района, письма в Адлер на армянском языке и материалы армянских культурных центров Сочи.

Чтобы перевести кандидата в `confirmed` или исключить его, добавьте строку в `labels.csv` и перезапустите скрипт.
